# Hyperframes

**Version:** 2
**Target:** `.skills/hyperframes`

## Description
Video rendering framework for AI agents to create videos using HTML, CSS, and JS.

## Capabilities & Use Cases
* **HTML Native Structure** : Define video structure effortlessly using familiar standard HTML tags
* **Data Attribute Timing** : Leverage `data-*` attributes to meticulously orchestrate start times, durations, and metadata across the entire composition
* **Deterministic Output** : Guarantee that every render produces the exact same high quality MP4 output reliably and repeatedly
* **Animation Agnostic Integration** : Work seamlessly with GSAP, Lottie, Three.js, and raw CSS animations to bring static elements to life
* **CLI Initialization** : Scaffold new video projects instantly with a dedicated initialize command
* **Live Realtime Preview** : Observe layout and styling changes as they happen directly in the browser with live previews
* **MP4 Artifact Rendering** : Render final high quality MP4 video compositions for direct distribution
* **Component Ecosystem** : Inject pre built robust visual blocks and templates easily via the component system
* **AI Agent Vibe Coding Workflow** : Built explicitly for AI agents generating semantic HTML structures, vanilla CSS, GSAP animated transitions, and integrating local assets natively
