# v0.14.0

## Features
* **Orbital Intro Toggle:** Added a new "Orbital Intro" toggle within the Spatial View sidebar to quickly enable or disable the Earth zoom-in sequence.

## Improvements
* **Canvas Deselection:** Clicking the empty void in the 3D space will now immediately clear the active room selection.
* **No Pre-selection:** Rooms are no longer automatically pre-selected when first landing on the Spatial page to eliminate confusion.

## Bug Fixes
* **Flexbox Layout Scroll Bleed:** Resolved a critical flexbox layout bug that allowed the hierarchy panel to push the main Spatial View beyond the bottom of the viewport, completely eliminating unintended page scrolling.
